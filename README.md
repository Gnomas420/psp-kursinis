# PartijaPro

SaaS sistema drabužių perpardavėjams: paskirsto nupirktos prekių partijos savikainą kiekvienai prekei, apskaičiuoja rekomenduojamą ir minimalią kainą, sudaro kainos mažinimo grafiką ir rodo partijos pelną.

Programų sistemų projektavimo kursinis darbas.
